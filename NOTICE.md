# Source and scope

Both tasks use Better Auth source at commit `e7200d132f5946490c19a389b5a89b31aeead4e7`. Copies of its MIT license are kept in the task folders. Better Auth is not affiliated with this repository.

The source packages remain unchanged on the development machine. This repository keeps the task artifacts and a repeatable replay command. It does not vendor the full upstream repository.

The tasks were prepared with AI assistance. The local checks verify the starting failures and reference fixes. They do not establish a model's solve rate or whether either task meets a particular platform's submission rules.
